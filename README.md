# Mugs & Kisses — сайт керамики ручной работы

Макет интернет-магазина фарфоровой посуды с акварельной росписью (Нижний Новгород).

## Структура

```
index.html            — все страницы сайта (главная, каталог, товар, о бренде)
css/style.css         — стили
js/main.js            — список товаров, каталог, переходы, поп-апы, формы
img/                  — логотип, значки разделов, фоны баннеров, фото мастер-классов
img/products/         — фото товаров
```

## Как открыть

Откройте `index.html` в браузере — сервер не нужен.
Для GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.

## Как добавить или изменить товар

В начале `js/main.js` есть массив `P`. Каждый товар — одна строка:

```js
{id:'limony', img:'lemons_deep', name:'Тарелка «Лимоны»', cat:'tarelki', sub:'glubokie', tags:['stock','hit']}
```

- `img` — ключ фото из объекта `IMG` (файл в `img/products/`)
- `cat` — раздел: `tarelki`, `chashki`, `vazy`, `plitka`, `shkatulki`, `igrushki`
- `sub` — только для тарелок: `malye`, `glubokie`, `bluda`
- `tags` — метки: `stock` (в наличии), `order` (под заказ), `new` (новинка), `hit` (хит продаж)

## Что пока заглушки

Цены `[ЦЕНА]`, размеры, сроки изготовления, телефон, e-mail, ИНН, ссылки на соцсети.
Формы (заказ, запись на мастер-класс, отзывы) работают только в браузере — для реальной отправки нужно подключить обработчик (например, Tilda, Formspree или свой сервер).
